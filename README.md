# 🐾 DoaPet — Site Oficial da ONG

O **DoaPet** é um projeto desenvolvido para representar uma ONG fictícia dedicada ao resgate, acolhimento e adoção responsável de animais abandonados.  
Este repositório contém o código-fonte completo do site institucional da ONG.

---

## 🧡 Sobre a ONG DoaPet

A **DoaPet** atua com foco em:

### 🐶 Resgate de animais
A ONG acolhe cães e gatos em situação de risco, oferecendo cuidados veterinários, reabilitação e um ambiente seguro até que possam ser adotados.

### 🏡 Adoção responsável
O processo inclui triagem, entrevistas, termo de adoção e acompanhamento, garantindo que cada animal encontre um lar definitivo.

### 👩‍⚕️ Reabilitação e cuidados
Com apoio de veterinários parceiros, os animais recebem:
- Vacinação  
- Castração  
- Tratamentos médicos  
- Acompanhamento diário  

### 📚 Educação e conscientização
A ONG promove campanhas sobre:
- Guarda responsável  
- Maus-tratos  
- Importância da castração  
- Adoção consciente  

### 🙌 Voluntariado
Voluntários auxiliam em:
- Resgates  
- Eventos  
- Administração  
- Divulgação  
- Lar temporário  

---

# 🌐 Sobre o Projeto do Site

Este site foi criado para ser:

✔ Responsivo  
✔ Moderno (degradês, sombras, dark mode, transições suaves)  
✔ Leve e funcional  
✔ Fácil de navegar  

Ele possui três páginas principais:

- **index.html** → Página inicial  
- **projetos.html** → Campanhas e ações da ONG  
- **cadastro.html** → Formulário para cadastro de voluntários  

As animações, contadores e modo escuro são controlados por JavaScript.

# 🧩 Descrição dos Arquivos

### **index.html**
A página inicial apresenta:
- Seção de destaque (hero) com animação  
- Estatísticas animadas (resgates, adoções, voluntários)  
- Sessões da ONG  
- Botão de doação  
- Dark mode  

### **projetos.html**
Página com:
- Cards animados  
- Listagem de campanhas  
- Grid responsivo  

### **cadastro.html**
Inclui:
- Formulário funcional  
- Validações básicas  
- Mensagem de confirmação  
- Animações de entrada  

### **style.css**
Contém:
- Tema claro e escuro  
- Gradientes  
- Tipografia (Google Fonts – Poppins)  
- Animações de scroll  
- Responsividade completa  

### **main.js**
Responsável por:
- Alternância de tema (dark/light)  
- Parallax do banner  
- Animação dos contadores  
- Observador de scroll (IntersectionObserver)  
- Função do formulário  
- Alerta de doação

# ▶ Como Rodar Localmente

1. Baixe o repositório  
2. Extraia o ZIP  
3. Abra a pasta no VS Code  
4. Certifique-se que *index.html* está na raíz  
5. Clique com o botão direito → **Open With Live Server**  
6. Pronto!
